# Cross-agent task handoff

Use [`docs/handoffs/TEMPLATE.md`](../docs/handoffs/TEMPLATE.md) for the tracked task record. Verify every handoff against Git, code, accepted documentation, and tests before relying on it.

```text
Objective:
Active branch:
Related issue or plan:
Current status: planned | in_progress | blocked | ready_for_review | completed
Completed work:
Remaining work:
Decisions made:
Assumptions:
Changed files:
Commands run:
Tests and verification (command, result, notes):
Known failures:
Risks and unresolved questions:
Human actions required:
Recommended next action:
Last updated:
```

Update this record at meaningful checkpoints, before an intentional pause or agent switch, and at the end of implementation. A handoff supports the execution plan; it does not replace it or override repository evidence.
