# Documentation rules

- Update the nearest source of truth; do not duplicate whole sections.
- Mark proposals and accepted decisions clearly.
- Use exact dates for decisions and external research.
- Commands must be copyable and state prerequisites.
- Never include real credentials, personal data or private URLs.
- Link behavior changes to issues/ADRs where available.
- Keep `AGENTS.md` concise; procedures belong in skills or dedicated docs.
