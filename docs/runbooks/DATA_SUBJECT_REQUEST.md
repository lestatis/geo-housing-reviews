# Data Subject Request Runbook

Use for access, correction, export, deletion, consent withdrawal or objection requests. Legal review determines exact rights and deadlines.

## Steps

1. Create a private case with request type and received timestamp.
2. Authenticate the requester proportionately; do not request excessive new documents.
3. Identify all relevant systems and processors.
4. Check legal holds, security/fraud needs and other lawful retention grounds.
5. Fulfil the request in structured, understandable form.
6. For deletion, propagate to primary stores, search indexes, media and scheduled backup expiry where immediate backup editing is not feasible.
7. Record actions and exceptions without retaining unnecessary request content.
8. Notify the requester of completion or reasoned limitation and appeal route.

## Search map

- identity/account;
- public profile;
- review drafts/versions;
- verification cases and raw evidence;
- reports/appeals;
- media;
- notifications;
- analytics identifiers;
- operational logs;
- backups/processors.

## Safety

Do not send another person’s data in an export. Review free-text and media for third-party personal data before release.
