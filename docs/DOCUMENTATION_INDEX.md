## Что не нужно создавать сейчас

Не заводить отдельные документы только ради полноты:

- полный `ALL_DOCUMENTATION.md` с копированием содержимого;
- отдельный package tree, пока структура отражена в README и реально меняется;
- release handbook до появления релизного процесса;
- production SRE runbooks до первого production-окружения;
- микросервисный каталог до появления микросервисов;
- отдельный `CODEX.md`: Codex использует `AGENTS.md`;
- дублирующий большой `CLAUDE.md`: Claude импортирует `AGENTS.md`.

## Правило актуальности

Когда поведение меняется, обновляется ближайший источник истины. Не добавлять новый документ, если достаточно исправить существующий. Повторяющееся правило для агента переносится в `AGENTS.md`, scoped rule или skill только после реального повторения ошибки.
