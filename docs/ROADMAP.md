# Roadmap

This is outcome-oriented. Convert items into issues with acceptance criteria; do not implement the roadmap as one task.

## Phase 0 — Discovery and foundations

- validate problem through renter/buyer interviews in Batumi and Tbilisi;
- select first city and launch languages;
- map property/address data sources;
- legal/privacy consultation;
- choose auth, hosting and map provider through ADRs;
- Figma user flows and clickable prototype;
- scaffold monorepo, CI and local environment.

Exit: tested prototype, agreed MVP, first technical ADRs.

## Phase 1 — Catalogue and search

- property domain;
- address normalization and aliases;
- map/list search;
- add-property flow;
- duplicate/merge admin queue;
- property detail skeleton.

Exit: users can reliably find or propose target objects.

## Phase 2 — Reviews

- review composer;
- category definitions;
- drafts, versions and publication state;
- review feed and transparent filters;
- media pipeline;
- account/profile basics.

Exit: safe unverified reviews can be submitted and displayed.

## Phase 3 — Verification and moderation

- verification case/evidence pipeline;
- initial methods;
- moderation queues and reason codes;
- reports, appeals, right of reply;
- audit log;
- ranking baseline and abuse protections.

Exit: trusted public beta can operate without database intervention.

## Phase 4 — Beta hardening

- observability and alerting;
- data export/deletion;
- backup restore drill;
- load and abuse testing;
- accessibility and localization review;
- incident/content runbooks rehearsal;
- analytics dashboards.

Exit: limited public launch.

## Phase 5 — Product validation

- compare feature;
- subscriptions/notifications;
- issue timelines;
- stronger verification partnerships;
- contributor reputation;
- search quality improvements.

## Phase 6 — Listings module

Only after reviews show sustained value:

- listing ingestion/creation;
- price and status history;
- fraud and duplicate detection;
- contact privacy;
- seller/agent verification;
- sponsored placement clearly separated from organic reviews;
- monetization experiments.
